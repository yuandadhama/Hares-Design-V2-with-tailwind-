# Hares Design – Digital Gallery Website

A simple gallery website created to showcase digital artwork in a clean and visually focused layout.

This project was originally made as a **personal request from a friend** who wanted a place to display their digital designs like an online gallery.  
Although the project was built some time ago, it has now been uploaded to GitHub as part of my portfolio documentation.

---

## ✨ Project Overview

Hares Design is a static web project that focuses on:
- Displaying digital images in a gallery-style layout
- Keeping the design clean and minimal
- Making the artwork the main visual focus

The project uses **basic web technologies** and was created as part of my early learning journey with Tailwind CSS.

---

## 🛠 Tech Stack

- **HTML** – Page structure  
- **Tailwind CSS** – Styling and layout  
- **JavaScript (Basic)** – Simple interactions and behavior  

---

## 📸 Features

- Responsive gallery layout
- Clean and minimal UI
- Lightweight and fast loading
- Focused on visual presentation of digital artwork

---

## 🎯 Purpose of This Project

- Practice using **Tailwind CSS** for layout and styling
- Create a real-use project based on a client/friend request
- Learn how to structure a simple static website
- Archive an older project as part of my development journey
